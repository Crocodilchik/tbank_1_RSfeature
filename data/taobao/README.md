## Схема данных

### UserBehavior.csv (без заголовка, имена назначает adapter)

| № | Колонка | Тип | Описание |
|---|---|---|---|
| 1 | user_id | int64 | Анонимный пользователь |
| 2 | item_id | int64 | Товар |
| 3 | category_id | int64 | Плоская категория товара |
| 4 | behavior | string | pv/cart/fav/buy |
| 5 | timestamp | int64 | Unix seconds UTC |

## Ключевые поля (маппинг к единой схеме проекта)

| Роль | Исходная колонка | Единое поле проекта |
|---|---|---|
| Пользователь | user_id | user_id |
| Товар | item_id | item_id |
| Время | timestamp | timestamp; timestamp_ms=null |
| Событие | behavior | event_type и label |
| Категория | category_id | metadata category_id, availability из config |

Служебные event_id/source_row_id/user_event_seq/split/target_cutoff_ts добавляет
генератор по [PIT §9](../../docs/point_in_time_policy.md), не исходные файлы.
Metadata хранится отдельно от events, в частности category не дублируется на
каждую строку большого журнала.

## Маппинг событий

pv→label0, cart/fav→1, buy→2. Primary event_type=buy;
repeat_purchase_policy=allow_previous. Fav — отдельная ветвь, не обязательный
промежуточный шаг покупки. Fallback cart отдельно от primary. Все модели
оценивают общий last eligible primary event пользователя в valid/test.

## Известные аномалии и особенности

- Без заголовка: нельзя потерять первую строку, ошибочно включив header=true.
- Пропусков исходных пяти полей0 по историческому отчету. Неизвестный behavior fatal.
- 49 лишних строк по ключу(user,item,behavior,timestamp) исторически; он не
  включает category. Exact dedup по пяти исходным полям, число измерить,
  конфликтующие category не склеивать как доказанные дубли.
- Полный timestamp rescan2026-10-19 подтвердил318 отрицательных и1094 >=2018-01-01.
  Старые3112 «вне правдоподобного окна» отозваны: граница не определена.
- Фильтр UTC [2017-11-24,2017-12-04), затем dedup. Окно100135088 rows,
  вне окна15719. Числа до dedup, не готовый processed размер.
- Полный scan2026-10-19 выявил изменяемый item→category mapping. Основной режим
  observed_asof; static_assumed отвергается при конфликте. Одновременный конфликт
  дает unknown=-1 и audit flag; глобальное majority по будущему не используется.
- Нет category tree, brand, цены или demographics; искусственная иерархия
  только отдельная ablation. Целевое время seconds UTC, равные секунды атомарны.

## Статистика

Исходный raw-отчет:987994 users,4162024 items,9439 categories во всей выгрузке.

Полный пересчет только времени2026-10-19:

| UTC split (до dedup) | Строк |
|---|---:|
| Train [2017-11-24,2017-12-02) | 74233131 |
| Valid [2017-12-02,2017-12-03) | 13940949 |
| Test [2017-12-03,2017-12-04) | 11961008 |
| Итого выбранное окно | 100135088 |

Локальная проверка временного окна: pandas C-parser,
только timestamp, chunks2M. Unique counts, средние плотности и singleton shares
**именно принятого UTC-окна не определены в отчете**. Старые100.12 events/user,
23.88/item,0.01%/29.06% singleton относились к неопределенному «чистому окну»
98915140 rows и здесь не выдаются за корректные показатели выбранного окна.

Temporal cold start по пользователям и товарам после принятых splits:
**не определено в отчете**; измеряется генератором относительно train cutoff.
Доли сущностей с одним событием — singleton shares, не cold-start rates.
Плотность events/(U×I) при повторяющихся парах не равна точно заполненности
матрицы уникальных user-item пар; исторические оценки трактуются как ориентир.
