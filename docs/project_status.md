# Статус проекта: Рабочий концепт

Дата фиксации: 2026-10-20.

Проект завершён в объёме рабочего концепта по решению заказчика. Дальнейшее
полное исследование вынесено за рамки этой поставки. Фоновые очереди остановлены.

## Что входит в поставку

- Адаптеры четырёх датасетов, строгие временные разбиения и PIT-политика.
- Prefix sampling обучающих негативов, personas, общие evaluation pools,
  flat/graph/sequence exporters, схемы и quality gates.
- Baseline GBDT, AutoML, GraphSAGE, Sequential Two-Tower, Fusion.
- Soft-target distillation и score-feature stacking с temporal OOF provenance.
- Калибровка, ранжирующие метрики, cold-start cohorts, paired bootstrap/Holm.
- Изолированные runners/collectors синтетических, objective и component ablations.
- Проверки конфигураций, source/config hashes, измерение ресурсов и журналы запусков.

## Что проверено

Последний полный локальный suite: 180 passed, покрытие с учётом ветвей95,86%.
Четыре теста требуют реальных raw datasets; остальные176 используют fixtures
и запускаются без скачивания датасетов. Neural dependencies нужны и для fixture tests.
Проверка публикации:176 fixture tests прошли в чистой копии без raw datasets,
покрытие95,73%; отдельно прошли все4 real-data tests. Результаты записаны в
[verification.json](results/verification.json).

Все пять моделей и оба варианта дистилляции прошли real-data smoke на Retailrocket.
Генератор проверен на ограниченных данных всех четырёх источников и полностью
выполнен для Retailrocket и MovieLens. Числа и методика — в
[результатах](experiment_results.md).

## Что осталось за рамками

Полная матрица4×5 с тремя seeds не выполнена. Полные модельные запуски,
полная дистилляция и ablations не завершены. Yoochoose прерван на генерации;
Taobao полностью не подготовлен. Дополнительные проверки повторов, evaluation
negatives, oracle horizon, полной Taobao metadata-off, альтернативных Yoochoose
tasks и MovieLens genome остаются частично нереализованными либо невыполненными.

Преимущество Advanced, статистическая значимость на полных данных и сокращение
ручного труда не доказаны. Production deployment, SLA, нагрузочное тестирование
и использование с реальными пользователями в поставку не входят.

## Воспроизведение и публикация

См. [инструкцию запуска](usage.md). Данные и бинарные артефакты не включены;
следует самостоятельно соблюдать условия их источников. Источники notebooks
публикуются без outputs; таблицы и графики генерируются локально.
Публичная история начинается с очищенного снимка рабочего концепта.
Внутренняя история разработки сохраняется локально в ветке
`codex/internal-development`; локальные артефакты остаются в исходном checkout.
